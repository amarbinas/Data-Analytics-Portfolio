# Blinkit Sales Analysis Dashboard

## Project Overview

This project focuses on analyzing Blinkit sales data using Microsoft Excel and presenting key business insights through an interactive dashboard.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Excel Formulas

## Project Highlights

* Sales performance analysis
* Category-wise sales analysis
* Outlet-wise sales analysis
* Interactive dashboard creation
* Data analysis and visualization

## Project Objective

To transform raw sales data into meaningful insights and present the results through an interactive Excel dashboard.
