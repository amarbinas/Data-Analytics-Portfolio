# E-commerce Sales Analysis Using Excel

## Project Overview
This project analyzes e-commerce sales data using Microsoft Excel to understand sales performance, customer purchasing behavior, product popularity, and delivery performance.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Data Analysis
- Dashboard & KPI Analysis

## Dataset Overview
- Total Records: 2,400
- Total Orders: 2,400
- Total Quantity Sold: 11,997

## Key Performance Indicators
- Total Sales: $649,019.80
- Average Customer Rating: 3.96
- Average Delivery Time: 2.34 Days

## Analysis Areas
- Sales trends over the last 13 weeks
- Customer purchasing channels
- Product popularity
- Customer gender distribution
- Customer location analysis
- Order delivery performance
- Customer ratings

## Project Objective
To analyze e-commerce transactions and generate meaningful insights that support better business decisions.
