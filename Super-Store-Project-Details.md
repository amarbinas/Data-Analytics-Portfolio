# Super Store Sales Analysis Using Excel

## Project Overview
This project analyzes Superstore sales data using Microsoft Excel to understand sales performance, regional trends, category performance, and profitability.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Dashboard Creation

## Dataset Overview
- Total Orders: 9,994
- Total Sales: $2,297,200.86
- Total Profit: $286,397.02

## Key Performance Indicators
- Average Sales: $229.86
- Average Profit: $28.66

## Analysis Areas
- Region-wise Sales Analysis
- Category-wise Sales Analysis
- Region-wise Profit Analysis
- Sales Performance Dashboard

## Project Objective
To analyze sales and profit data, identify business trends, and present meaningful insights through an interactive Excel dashboard.
